# Metsäpalsta

GitHub Pages -versio. Julkaise `index.html`, `manifest.webmanifest` ja `sw.js` repositorion juuressa.

## Huomioitavaa
- OSM-kartta ja Leaflet-kirjasto vaativat verkkoyhteyden ensimmäisellä latauskerralla.
- Metsäkeskuksen WFS-haku on kokeellinen: selainrajoitukset tai rajapinnan muutos voivat estää haun.
- Omien palstojen tiedot tallentuvat vain selaimen localStorageen. Tee JSON-varmuuskopiot säännöllisesti.
- GitHub Pages -osoite on julkinen; älä lataa henkilökohtaisia metsävaratietoja repositorioon.
- GPS toimii HTTPS-osoitteessa käyttäjän luvalla.
